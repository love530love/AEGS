# ADR-0003: 可信接管先于自治扩展

- 状态：Accepted
- 日期：2026-11-15

## 背景

当前原型已有发现、交接、提案、反馈和本机控制台，但审批身份由输入字段声明，JSONL 哈希链不能抵御整体重写，且交接包未对 Git、账本头与快照内容建立完整有效性约束。

## 决策

在实现能力雷达、动态专家组织、多 Agent 编排或自动检索/安装前，优先实现可信接管、过期检测、结构化高风险决策、事件一致性和治理文件的内容绑定。原型在该阶段继续明确标识为单机演示用途。

## 后果

短期会降低“自主进化”功能的表观速度，但能避免在错误、过期或可伪造状态上继续自动化。后续自治能力只能消费通过 P0 门控的项目状态。
