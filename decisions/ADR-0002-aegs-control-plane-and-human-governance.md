# ADR-0002: 控制平面、项目治理包与人类治理入口

- 状态：Accepted
- 日期：2026-09-12

## 决策

AEGS v0.2 采用控制平面与执行数据平面分离。每个受管项目使用版本化 `.aegs/` 治理包；高影响操作通过策略判定点门控。新增人类治理控制台、HumanDirective、标准化接管包和受控 Capability Radar。

## 原因

仅有多 Agent 或对话摘要不能支持可信接管、持续审计或人类高质量决策。项目状态、授权、证据、回滚和反馈必须成为独立、可版本化的第一等对象。

## 后果

实现初期增加事件建模、界面和适配器成本；但能在不绑定单一 Agent/模型的情况下，把自动化限定为可验证实验，并把最终价值取舍保留给人类。
