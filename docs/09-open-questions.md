# 开放问题账本

以下问题未被 v0.1 假装解决，是后续研究与实验的明确对象：

1. AI 在什么条件下可以挑战或建议修订治理规则，而不形成自我授权？
2. 多专家在何种任务、成本和证据条件下确实优于单体或小组合？
3. 如何防范专家群体的共同偏差、虚假共识和角色同质化？
4. 如何判定一次提升不是短期过拟合、数据泄漏或评估投机？
5. 如何证明新 Skill 有跨任务迁移能力，而非只复述训练/历史案例？
6. 如何量化和防止持续进化造成的既有能力退化？
7. 如何设计可扩展的 Trace 存储、敏感数据分级与证据保留期限？
8. Meta-Evolution 可以安全修改到什么粒度，谁有批准权？

每一项在实施前应转化为可检验假设、实验设计、风险清单与决策记录。
