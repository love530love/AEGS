# 治理与宪法边界

## 宪法原则

1. 人类授权和明确范围优先。
2. 进化不得绕过安全、隐私、合规和资源限制。
3. 生产变更前必须有可追溯证据与可回滚路径。
4. 审计角色和 Red Team 不从属于提案者。
5. 基础模型、宪法和高风险权限不由 v0.1 自动修改。

## 进化权限

| 级别 | 示例 | 处理 |
|---|---|---|
| GREEN | 沙箱提示词、检索排序、小范围工作流试验 | 可自动实验，记录审计 |
| YELLOW | Skill/角色/评估规则晋级 | 需独立评估和指定批准 |
| RED | 权限扩大、生产工具写入、宪法/基础模型改变 | 默认禁止或需明确人类最终批准 |

治理规则本身可以被研究和提出修订，但其提案不能自行生效；必须走比普通能力更严格的 RED 流程。
