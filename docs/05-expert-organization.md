# 动态专家组织

专家是具备职责、输入契约、输出契约、权限与评估方式的角色实例，而不是永久固定的 Agent。

## 基础组合

- 低风险任务：Planner + Executor + Verifier。
- 高复杂度设计：Architect + Domain Expert + Security + User Advocate + Red Team + Synthesizer。
- 系统演进：Research、Engineering、Risk、User、Evolution Councils，加独立 Judge/Auditor。

## 权力分离

Researcher 提供证据；Expert 提供专业判断；Critic/Red Team 提供反例；Synthesizer 汇总方案；Judge 比较候选；Executor 执行；Auditor 核验溯源；Human 保留最终治理权。

## Capability Gap Detection

当同类任务持续出现低覆盖、低成功、过高返工或外部依赖不足时，系统可以提出新增 Skill/Role。提案必须含适用范围、证据、试运行计划、预算、风险和退出条件；不允许直接常驻化。
