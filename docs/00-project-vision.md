# 项目愿景

## 定义

AEGS 是“可审计的能力进化闭环”：系统从任务执行中获得经验，以 Trace 作为事实基础，以证据约束诊断，以受控实验验证候选改变，并只在满足治理条件后将改变晋级为新版本。

它追求的不是无限自我修改，而是 **在不失去控制、可解释性和既有能力的前提下持续改进**。

## 非目标

- 不是单一超级 Prompt。
- 不是为每个任务默认启动的多 Agent 辩论。
- 不是允许系统自行改写基础模型、宪法或生产环境。
- 不是把失败记录删除以制造“持续成功”的表象。

## 长期方向

从静态执行逐步进入反思、适应和进化；最终研究 Meta-Evolution：系统如何通过严格验证改进“如何进化”的机制本身。
