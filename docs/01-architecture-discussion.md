# 架构讨论沉淀

本项目由原 Prompt 方向独立而来。早期关注点是“让 AI 不盲从用户”和多专家讨论；讨论后形成以下调整。

1. 自进化的关键不是修改模型，而是把可验证经验重新注入运行时能力。
2. Memory 不足以承载因果、实验和失败信息，应升级为 Experience System；Memory 是其子系统。
3. Trace 不只是日志，而是反思、审计和进化引用的事实层。
4. Skill 是可执行、可评估、可版本化、带溯源的经验压缩结果。
5. 专家是动态实例化的治理角色，不应成为固定且永远在线的“角色扮演群”。
6. 评估不能只比较单一分数；必须考虑迁移、稳健性、安全、成本和回归。
7. 进化必须在 Shadow Lab 中进行候选验证，生产系统不得被直接试验。

讨论中提出的核心架构视角是四个相连的世界：Human（授权与利益相关方）、Cognitive（推理与组织）、Experiment（沙箱与试验）、Governance（证据、版本、审计、晋级和回滚）。它们由 Event、Evidence 与 Decision 连接。
